# W.E.St. Vietnam static website

This folder contains the clean static build of the W.E.St. Vietnam website.

Deploy the contents of this folder as the website root. The site is plain
HTML/CSS/JS with local assets under `wp-content`, `css`, `js`, and `images`.

Preview locally:

```bash
python -m http.server 8090
```

Then open:

```text
http://127.0.0.1:8090/
```
