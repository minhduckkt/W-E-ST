IOA-312 là adapter chuyển đổi IO-Link Class A sang Class B, cho phép kết nối PAM-190-P-IO với IO-Link Master tiêu chuẩn. Bao gồm nguồn 24V/2.5A tích hợp. Kết nối M12 5-pin. Hỗ trợ phần mềm PACTware + Turck USB-2-IOL-0002. IODD file tải từ w-e-st.de hoặc IODDfinder.
